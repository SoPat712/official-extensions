# Identicon (offline)

Draws a 64x64 pattern from the domain name. The same domain always gets the same icon.

It makes no network requests, so it suits Tor, offline instances, or anyone who doesn't want a favicon service to see their result domains.

Put it last to fill gaps when other providers find nothing. Put it first, or use it alone, to send no favicon requests at all.

## Settings

- **Style**: `squares` (default) for blocks, `dots` for round cells.
